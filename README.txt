DESSERT PORTFOLIO - WEBSITE PACKAGE
===================================
index.html : the whole website. Open it in a browser, or use it as the site's home page.
images\    : every photo the site uses. All names are plain English (no Chinese characters).
             Links inside index.html are relative, e.g.  images/apple-pie.jpg

Notes
- Fully static: no build step, no server code. Upload index.html + the images\ folder.
- Fonts load from Google Fonts over the internet. The site still looks fine offline.
- Keep index.html and the images\ folder side by side.
